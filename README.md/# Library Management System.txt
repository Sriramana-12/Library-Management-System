## Technologies Used

- **Database:** PostgreSQL
- **Admin Tool:** pgAdmin 4
- **Frontend:** HTML, CSS, JavaScript (planned)
- **Backend:** Python, SQL
- **IDE:** Visual Studio Code

## Database Schema

The database includes the following tables:
- publishers
- categories
- authors
- books
- book_authors
- book_copies
- members
- staff
- loans
- reservations
- fines

## How to Run

1. Install PostgreSQL
2. Open pgAdmin or psql
3. Execute `database/library_management.sql`
4. Run queries from `database/queries.sql`
